# Torque hinges for the folding thumb

The KobitoKey build guide shows one torque hinge per hand. Two M2 screws and washers secure each assembly. The maker also describes how loosened hinge screws cause wobble. The expanded MX prototype currently uses a printed hinge with an M3 axle and a separate index screw. [Maker's build guide](https://note.com/11_50iii/n/n75cff4d3502c)
