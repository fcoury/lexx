# Design sources

- The key positions follow the case project's measurements of the KobitoKey v1.0.1 mechanical release. The maker's kit guide shows separate finger and thumb/controller boards, hot-swap sockets, a flat flex and two wireless halves. The published firmware documents the original XIAO matrix. The PCB artwork, expanded schematics and firmware configuration in this directory were drawn for this case. The maker's public release did not include editable PCB files or fabrication artwork. [KobitoKey release](https://github.com/juichi50iii/KobitoKey_QWERTY/releases/tag/v1.0.1) · [Build guide](https://note.com/11_50iii/n/n75cff4d3502c) · [Original matrix](https://github.com/juichi50iii/KobitoKey_QWERTY/blob/1c81c9ba25f03d0a35d67c565c3dffc0f47327f0/config/boards/shields/KobitoKey/kobitokey.dtsi)
- The MX hot-swap land pattern and socket STEP model come from foostan's keyboard library, copyright 2020 foostan, under the MIT license. [Library](https://github.com/foostan/kbd) · [License text](licenses/foostan-MIT.txt)
- The XIAO land pattern derives from Seeed Studio's XIAO-nRF52840-SMD footprint. This carrier omits four unused debug/NFC test lands next to the board edge. The adapted footprint uses the same CC BY-SA 4.0 license. [Seeed source](https://github.com/Seeed-Studio/OPL_Kicad_Library/blob/master/Seeed%20Studio%20XIAO%20Series%20Library/XIAO-nRF52840-SMD.kicad_mod) · [License text](licenses/CC-BY-SA-4.0.txt)
- The Hirose FH12, JST PH, SOD-123 and PCM12 footprints derive from the KiCad libraries. Local naming and electrically isolated connector mounting tabs were adjusted for this design. These footprints use CC BY-SA 4.0 with the KiCad libraries exception. [KiCad library license and exception](https://www.kicad.org/libraries/license/)
- The firmware runs on the ZMK and Zephyr projects. The firmware directory contains the keyboard-specific configuration and its pinned manifest. [ZMK](https://github.com/zmkfirmware/zmk) · [Zephyr](https://github.com/zephyrproject-rtos/zephyr)
- KiCad's 3D viewer uses local approximate assembly envelopes for the controller and battery socket. They show placement and plug direction. Use the manufacturer's drawings and the case measurements for physical fit. [Seeed package drawing](https://www.seeedstudio.com/blog/wp-content/uploads/2022/08/Seeed-Studio-XIAO-Series-Package-and-PCB-Design.pdf) · [JST PH drawing](https://www.jst.com/wp-content/uploads/2021/08/ePH-new.pdf)
